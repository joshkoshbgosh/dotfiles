# time

Get the current date and time in ISO format.

## Usage

Ask me "what time is it?" or "get current time" and I'll return the current date and time in ISO 8601 format (e.g., "2026-01-15T20:36:00-0500").

## Implementation

This skill calls the system `date` command with your timezone (America/Toronto).

## Notes

- Returns time in ISO 8601 format with timezone offset
- Based on your local system time
